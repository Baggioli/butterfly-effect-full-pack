# 聊天建档验证记录

日期：2026-10-22。开发目录：/Users/lq/Documents/Codex/butterfly-effect。

## 实现
- 默认首次入口为约3分钟聊天；逐题询问，按已有信息与时间障碍调整顺序。年龄、学历、技能缺失时明确询问。
- 文字、快捷选项、点击录音共享流程。转写后先让使用者编辑再发送；麦克风被拒绝或服务故障时可文字继续。
- 初始聊天与未发送文字保存在当前浏览器，可关闭后续聊。语音不存储为文件，不自动发送给外部识别服务。
- “我的角色卡”可编辑；明确事实附原话依据，“有待确认的理解”单列，可确认或否定。理解不自动转为事实或限制路线。
- 确认角色卡后生成四幕故事；先审核，接受后才建立旅程，首章任务进入原有行动系统。
- 每14天要求近况确认，可录音、打字或选择没有变化。重要经历、兴趣逐步补充，历史任务和反馈保留。
- 档案页可直接编辑角色卡；只修改角色卡不会重置14天近况计时。
