# 蝴蝶效应本地开发

本地开发主目录：`/Users/lq/Documents/Codex/butterfly-effect`。

## 开始使用

直接打开 **http://127.0.0.1:4173** 即可进入，不需要输入应用口令。也可以双击打开蝴蝶效应.command，它只启动服务并打开页面，不再要求设置口令。

Mac 登录后会自动运行本地预览和 SSH 隧道；隧道断线会自动重连。Mac、DGX 的网络与现有 SSH 连接必须可用。`8787` 保留为 DGX 部署版本入口；`4173` 是当前本地前端源代码的预览入口。

## 后续开发

以后在 Codex 中选择这个本地文件夹作为项目，继续修改即可。不需要继续依赖手机会话传递代码。

- 修改 `public/app.js`、`public/story.js`、`public/style.css` 或 `public/index.html` 后刷新4173页面即可查看。
- 修改 `worker/api.js` 后，运行 `npm run deploy:dgx`。它会先执行测试、构建与验证，再更新独立 DGX 应用并重启该应用服务，不改动模型和其他容器配置。
- `npm test`：自动化回归。`npm run build`：生成嵌入资源的后端。`npm run validate`：验证构建。
- `npm run dev`：前台手动预览。如果自动预览已经运行，不要同时再启动一个相同端口的服务。
- `git status` 和 `git log` 可查看本地修改与版本记录；没有配置远程推送或自动云同步。

后端与模型继续运行在DGX。本机4173按用户要求免口令，仅监听回环并限制跨来源请求；底层进程间凭据仍保留，用户无需输入。手机入口由本人私网身份识别，不显示应用登录页。

手机入口：**https://spark-864f.tailfb7e5f.ts.net:8443/**。手机首次需安装Tailscale，使用与DGX相同的账号连接。随后用手机浏览器打开链接，可添加到主屏幕。手机服务运行在DGX上，不依赖Mac开机。手机和电脑的数据分别保存在各自浏览器，暂不自动同步。详见手机体验说明.md。

## 服务维护

Mac 本地预览：`launchctl print gui/$(id -u)/com.lq.butterfly-effect.dev`

Mac SSH隧道：`launchctl print gui/$(id -u)/com.lq.butterfly-effect.tunnel`

重启本地预览：`launchctl kickstart -k gui/$(id -u)/com.lq.butterfly-effect.dev`

停止本地预览：`launchctl bootout gui/$(id -u)/com.lq.butterfly-effect.dev`

停止SSH隧道：`launchctl bootout gui/$(id -u)/com.lq.butterfly-effect.tunnel`

重新安装这两个用户启动项：在本项目目录分别运行 `node scripts/install-mac-tunnel.mjs`、`node scripts/install-mac-dev.mjs`。

服务日志在忽略的 `.runtime/` 中；应用口令仍保存在 DGX 独立的权限受限状态文件中，本地预览只在进程内存中使用，不保存其副本。
