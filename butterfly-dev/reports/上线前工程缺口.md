## P0

1. **独立部署与端口**  
   - 禁止占用原 DGX：8787 / 8790–8793 / 4173 / 8443  
   - 新环境需：独立目录、独立 systemd（或等效进程管理）、独立端口（建议 18xxx）、独立口令  
   - 未授权不得执行 `deploy:dgx` / 原 install 脚本

2. **规划模型可用性**  
   - plan 默认走私有 Ollama；生产故事曾用 `qwen2.5:32b`，对话 `qwen2.5:7b`  
   - 需监控：模型是否在线、`/api/ai/status` reachable、超时/截断率、PLAN_* 错误码  
   - 云端 DeepSeek **未授权**，保持关闭

3. **HTTPS / 域名 / 中国合规入口**  
   - 公网 H5：HTTPS、域名、（若面向中国大陆公众）**ICP 备案**评估  
   - 现网手机入口依赖 Tailscale 私有身份，不能直接当公网获客页

4. **密钥与口令**  
   - `DGX_APP_PASSWORD`（≥16）仅环境变量或 `DGX_APP_PASSWORD_FILE`；禁止进 Git/聊天/日志  
   - 不提交 `.env`；仓库仅有 `.env.example`

5. **隐私（个人信息保护法）**  
   - 录音不落盘、转写后不保留原始音频（现设计）——上线文案需明示  
   - 无账号体系时的「导出/删除本地数据」入口需产品可见  
   - 禁止上传 `data-private/` 或真实用户包

## 语音：调参旋钮与真机清单（非真人验收）

### 代码层旋钮（`voice-turn.js` / `voice-output.js` / `speech_pacing.py`）

| 旋钮 | 位置 | 默认/说明 |
|------|------|-----------|
| `silenceMs` | SilenceGate | 1900ms 停顿结束一轮 |
| `noSpeechMs` | SilenceGate | 12000ms 无有效人声 → empty |
| `maxMs` | SilenceGate | 45000ms 上限 |
| `threshold` | SilenceGate | RMS 0.006 |
| `voicedMs≥200` | SilenceGate | 才算 hasSpeech |
| `speechChunks` limit | voice-output | 60 字分句预取 |
| speak 超时 | voice-output | 70s/句 |
| 语速 rate | speech_pacing | 0.85（下限 0.65） |
| 中文时长下限 | 交接说明 | 约 3.3 字/秒 |
| 浏览器语速 | native utterance | 0.98 |
| 录音上限 | onboarding | 2MB；类型 webm/mp4/ogg |

### 明显需留意点（代码审阅，非真机结论）

- 私有 TTS 失败才回退**本机中文** `speechSynthesis`；无本机中文声则报错——微信内置浏览器常见坑  
- 分句预取：一句失败会 `onError` 中断整轮；需真机看弱网  
- 切文字/暂停/离开会停麦与播报——逻辑有，需真机确认不残留权限指示灯  
- 静音/字幕幻觉拦截依赖服务端质量模块——勿用自动化 PASS 冒充真人

### 真机清单（待 Micheal 本人操作）

**微信内置浏览器 / iOS Safari / Android Chrome 各测一遍：**

1. 首次麦克风权限：允许 / 拒绝 / 系统层关闭后的提示与文字后备  
2. 连续语音：播报完毕才开听；短停顿不断句；说完长停顿自动送出  
3. 自动播放策略：无用户手势时能否播首句；锁屏/切后台后恢复  
4. 键盘：文字模式输入、Ctrl/⌘+Enter、与语音切换无丢草稿  
5. 角色卡确认后「展开故事」失败：是否保留卡片、是否出现「重新展开故事」与可读错误  
6. 勿用模拟 TTS/假 ASR 报告勾选「真人通过」
