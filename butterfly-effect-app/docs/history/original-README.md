## V0.1 历史记录

移动端优先的交互原型。HTML/CSS/JavaScript，无依赖安装或构建步骤。

## 本地运行

在 dist 目录使用静态 HTTP 服务即可。Sites 使用 .openai/hosting.json 声明的 dist 目录。

## 已实现

- 三步个人档案与目标创建，可编辑和保存。
- 副业、作品集、阅读、通用目标四类本地规划模板。
- 基于技能/经历和每周可投入时间的任务差异化。
- 成长章节、日周月计划、执行反馈、周月复盘和成果记录。
- 障碍分类调整草案，接受、拒绝、进一步减量及撤销。
- 保留历史任务和调整版本，未反馈不自动判断完成。
- 行为观察确认/纠正/删除与关闭学习开关。
- 独立示例情境、两位用户对比、JSON导出。

## 边界

这是浏览器原型，不是已提交微信平台审核的原生小程序。当前没有真实模型、账号、服务端数据库、跨设备同步、推送或自动后台学习；规则只覆盖演示场景。长期路线为阶段模板，后续阶段仍需补充专业规划。所有个人资料仅存当前浏览器 localStorage，清除浏览器数据会丢失；可先导出备份。Demo不输出成功概率，不保证实现目标。

## V0.2 · 小程序版面与基础功能修复

- 全部页面统一手机单列，默认390px；桌面预览可切换375/390/430px，手机按可用宽度适配（上限430px）。底部导航、弹窗滚动区与固定操作栏独立处理。
- 去掉外部字体请求，表单输入16px以降低手机聚焦自动放大的影响；增加安全区与viewport-fit。
- 修复长文本必填与空白校验；任务标记完成须记录产出，未知状态不能夹带执行反馈。
- 今日与日计划共享下一任务选择，已完成任务不能被最低版本入口误降级。
- 日/周/月视图各自保存选项，周/月成果与笔记按周期筛选，历史归档执行用时保留。
- 档案修改先形成待确认草案；拒绝保留原值，接受后才保存；撤销同时恢复对应档案与章节，保留新反馈。
- 增加阶段成果确认、下一章任务草案、模拟周期撤销及旅程切换入口。
- 修复观察纠正/删除对未来建议的影响，关闭学习后不调用已存行为推断。

验证：375/390/430px下5个主页面共15组宽度检查无横向溢出；375px弹窗底部操作可见、长内容可滚动。浏览器完成新建档案、必填异常、任务完成/部分完成、下一任务、认识纠正/关闭学习、成果记录、章节推进与撤销、模拟周期回退、刷新保留、记录导出与旅程切换。导出JSON已解析验证。规则回归测试通过。尚未在微信原生小程序和真实iOS/Android设备上验收键盘与系统安全区。

## V0.3 · 人生故事与角色系统

- 明确参考 LifePilot 的目标到行动拆解，TheGreatMe 的主线与复盘关联，以及 Habitica 的成长反馈；应用内提供参考说明和官方链接。原创插画与界面，不复制品牌或游戏素材。
- 角色录入升级为6步、30余项信息：身份/教育/工作年限、重要经历、技能熟练度与证据、资源、日程、家庭责任、时间与专注预算、障碍/尝试/支持、理想生活/长期方向/90天成果与验收。草稿可刷新续填，修改仍需确认。
- 四幕剧情包含叙事、场景、事件、成果门槛和3种条件分支；半年/一年/三年为条件式远景。分支记录与实际成果进入叙述；现实条件变化进入可审核的调整草案。未来事件仅预览，不自动安排。
- 四类目标使用具体事件库；每个任务提供工具、时段、地点、带用时步骤、交付物、示例话术和最低版本。步骤勾选持久化，与任务完成确认分开。低预算或低专注时长下缩小产出而非仅压缩时长。
- 加入原创等距生活场景、地图节点、角色卡、行动经验与轻量章节成长。经验值仅表示活动记录，不是能力或成功评分。
- 输入编辑器改为全高独立三行布局（标题/滚动内容/操作栏）；适配 visualViewport 的高度与偏移，聚焦自动滚动，输入16px且深色实底，导航在编辑时隐藏。
- 兼容旧记录：已完成与已有反馈任务保留；当前周未反馈任务更新为具体模板，保留原任务ID与旧标题。

验证：原规则回归测试全部通过，新增四类目标的四幕/事件/分支门槛、任务步骤时长预算、剧情动态反馈与分支到调整草案检查。浏览器完成6步建档、刷新续填、具体任务与勾选保存、完成反馈与经验变化、未来章节预览、分支记录与任务调整。375/390/430px真实iframe视口的5页面共15组无横向越界；375x420下短输入及底部长文本均完整位于页头和操作栏之间。尚未在真实手机微信键盘/原生小程序上验收，不将缩短视口模拟描述为真实IME测试。


## V0.4 快速建档与真实AI接口
- 首次建档保留年龄与学历，并收集90天目标、每周可用小时。自述支持粘贴简历文本及手机键盘语音输入；不含附件解析或独立录音。
- AI提取后确认档案，规划后审核草案；接受、撤销沿用版本记录。关闭行为学习后，AI重规划不发送反馈或观察。
- 服务端 DeepSeek API：`DEEPSEEK_API_KEY`（secret），`AI_MODEL`（默认 deepseek-flash）。通过 Sites 运行时环境配置；不能写入前端或Git。此版本未配置真实密钥，无法完成真实模型端到端验证。
- 官方 API 参考：https://api-docs.deepseek.com/api/create-chat-completion/ ；JSON结构化输出：https://api-docs.deepseek.com/guides/json_mode/ 。
- `/api/ai/status` 必须登录；`/api/ai` 必须登录且同源。提取字段白名单、故事结构校验、排程预算限制、超时与错误不回显供应商响应。
- 记录仍为浏览器本地保存。推送、跨设备同步、正式微信小程序与大规模公开运营的限流/费用上限尚未实现。保持所有者私有访问。
- 无密钥不调用外部模型，也不悄悄回退为模板。模板入口单独标明。
- 构建：`bash scripts/build.sh`；验证：`node test.mjs && node test-ai.mjs && node scripts/validate-artifact.mjs`。
