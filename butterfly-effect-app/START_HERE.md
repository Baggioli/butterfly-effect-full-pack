# 蝴蝶效应：给接续开发模型的入口

这是独立协作开发版本，与 moongrains 项目完全无关。不得将代码推入 moongrains，也不要覆盖原有 Mac/DGX 运行目录。

## 先阅读
1. `PROJECT_VISION.md`：产品构思与用户需求。
2. `CURRENT_STATE.md`：已完成、实测边界与待办。
3. `ARCHITECTURE.md`：源码入口、数据结构、模型与部署。
4. `需求文档-聊天式建档.md`：按日期累积的具体需求。
5. `DESIGN.md`：视觉风格。
6. `DGX.md`、`本地开发说明.md`、`手机体验说明.md`：部署历史和私有访问方式。

## 工作方式
- 从此仓库新建开发分支，作为独立版本迭代；先验证，再通过提交或补丁合并。
- 不擅自修改原 DGX 现有应用、Ollama、Docker、Tailscale、OpenClaw、驱动或其他服务。
- 需要实机部署时，先确认使用者授权的独立目录、端口和服务名称；原仓库的部署脚本会更新原应用，不要直接执行。
- Node 20.19+；前端与接口不需要 npm install。执行 `npm test`、`npm run build`、`npm run validate`。
- Python 语音依赖必须在独立环境安装，TTS 和 ASR 的 transformers 版本不同，不要混装。
- 不把示例任务、模拟接口或合成语音测试冒充真实用户验收。
- 个人真实数据在另一个本机交接压缩包内，没有上传到本仓库。未知资料不能自行填充。

## 可运行入口
仅预览界面：`python3 -m http.server 4174 --bind 127.0.0.1 --directory public`，打开 http://127.0.0.1:4174 。该入口没有模型接口，语音和规划不会因此自动接通。
原环境全功能：`npm run dev` 依赖已有 SSH 别名 dgx、8787 隧道和服务端凭据；新开发环境需自行安全配置，不包含密钥或口令。
