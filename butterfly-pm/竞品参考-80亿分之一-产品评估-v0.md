# 竞品/参照评估：《80亿分之一》（1 in 8 Billion）→ 蝴蝶效应 · v0

> 来源：Micheal 经 Grok 建议（2026-10-28 约 20:06，Asia/Shanghai）。官方入口以 [1in8b.life](https://1in8b.life/zh-hans/about/) 为准（2026-10 公开；名称相近仿站勿混）。  
> 性质：**体验参照评估备注**，非对标竞品、不改本轮门禁与第 13–14 天主项。门禁仍【停转】。

## 1. 对方是什么

- 免费浏览器人生模拟：按 172 国真实统计**随机出生**，约每分钟过一年，活到生命表决定的终点。
- 节点：每年选「今年重心」；升学/工作/感情/移居/治疗等抉择由玩家点；可选「自动抉择」旁观。
- 名场面：同一秒出生的另外四人并排走过；5/15/30/50/70 岁「暂停片刻」提问；死后死亡纪录/前世纪录；可选珍藏通行证做影片相簿（非核心玩法）。
- 调性：人生偶然、只有一次、努力改变可能性但难完全摆脱出生地统计；重数据出处、免责、15+、教学版降沉重内容。

## 2. 与蝴蝶效应的本质差异（先划清，避免抄错）

| 维度 | 80亿分之一 | 蝴蝶效应（我们） |
|------|------------|------------------|
| 主角 | 抽签来的「陌生人」一生 | **用户自己**的条件与目标 |
| 核心体验 | 命运抽签 + 旁观/轻选择 | **计划线 vs 实际线** + 今日可执行小事 |
| 时间感 | 压缩一生（30–90 分钟） | 日常节奏（日/周重算、任务） |
| 价值主张 | 共情偶然与不平等 | **努力可见地改变轨迹**（模拟非承诺） |
| 数据角色 | 宏观统计驱动剧情概率 | 城市×职业等参数校准推演区间 |

**结论**：可借鉴的是**叙事节奏、对照感、反思停顿、出处透明**；不可照搬「随机出生 / 旁观一生」作为主钩子——会冲淡我们的护城河（个人推演 + 执行反馈）。

## 3. 可借鉴点（按故事 / 推演 / 两线）

### 3.1 故事体验

| ID | 借鉴点 | 对我们意味着什么 | 建议档位 |
|----|--------|------------------|----------|
| A1 | 关键年龄「暂停片刻」提问 | 里程碑到达时短暂停：一句反思/可选留一行字，再继续故事或任务 | **P1 体验**（主项后） |
| A2 | 死后「这一生回顾」纪录 | 阶段结束或第 7/30 天复盘卡：处境→行动→变化→代价汇总（对齐已有故事节点四要素） | 与周报/复盘合流，勿另开大需求 |
| A3 | 一年一年推进的可读节奏 | 长文故事分段锚点（年龄/阶段标题）+ 可选「下一段」；演示勿一次糊屏 | 故事加深验收可顺带检查 |
| A4 | 自动抉择 / 倍速旁观 | **仅演示/回看**：故事朗读或推演动画可跳过/加速；正式路径仍以主动选择与执行为主 | 演示友好；正式默认不开自动 |

### 3.3 两线 / 对照体验

| C3 | 可收藏/分享的「一生纪录」 | 分享卡继续只放计划线；复盘金句可选进卡（不进实际线细节） | 沿用拍板；素材后置 |

## 4. 明确不借鉴 / 红线

1. **随机出生抽签**作冷启动或营销主叙事（与「你的条件→你的路径」冲突）。  
2. **自动过一生**作正式默认（我们要用户领今日任务）。  
3. **平行他人人生**作两线替代或第三线（与 v1.26「不恢复维持现状线」、法务底线一致）。  
4. 把宏观「出生地决定论」写成产品卖点（我们强调可执行改变，同时诚实标模拟）。  
5. 对外话术混用「命运/注定/预言」（R8 仍禁）。

## 5. 产品结论（给 Micheal / 开发）

- **值得学**：里程碑反思停顿、故事分段节奏、出处透明、两线并排的视觉对齐、结束后的回顾卡与周报合流。  
- **不要学**：抽签人生、旁观为主、平行陌生人对照、数值条游戏化。
