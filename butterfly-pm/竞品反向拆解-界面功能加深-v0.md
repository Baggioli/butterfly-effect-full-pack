### 4.3 功能清单、主流程与映射

  - 对话式、语音日记
  - Go deeper 两种模式
  - 晨间意图与晚间反思
  - 今日目标
  - 周报

## 13. 可抄的界面与功能要点（12 条，按我方页面分组）

> 这些是界面和结构层面的借鉴，不涉及任何美术、IP 或文案原文。凡是只登录后才能看到的细节，都标了「未核验」，进开发前需要自己设计验证。与 v0 的 D1–D8 对应关系写在括号里。

### 推演页

1. **节点展开「本步变了哪几项 ↑↓」**
   - 借鉴：人生重开模拟器的 Play 屏【源码】
   - 抄什么：逐步日志加属性条的升降趋势动画。我方推演页点开里程碑节点时，列出能力、角色、生活状态各项比上一节点的升降，并用箭头动画表示。计划线、实际线用同一套组件。
   - 不抄：地狱 / 逆天 / 传说这类评级词、抽卡天赋、「垃圾人生」的调性；也不做人生总评。这符合法务的要求：两线差距不放大成结局好坏。

2. **顶部「当前阶段卡」**
   - 借鉴：BitLife 的头部【截图#1】
   - 抄什么：姓名、阶段标签、一个关键数，放在推演页顶部固定，例如「职业阶段：初级 → 目标里程碑 Y，预计还要 N 周」。
   - 不抄：红 / 橙 / 绿警告色（我方规则是推送不提醒落后，所以用中性色）；Boost 看广告换属性；Time Machine 付费回退；17+ 内容。阈值颜色属于【社区】说法，未核验。

### 故事

3. **执行解锁故事片段**（D1）
   - 借鉴：Finch 的能量 → 冒险 → 回来讲故事【帮助】
   - 抄什么：完成当日任务后，解锁或更新「今天的故事段落」（详细故事的计划线文学层，追加一小节）。只有出发时的一次轻量等待，结尾一句「明天继续」。
   - 不抄：宠物 IP 和美术、Rainbow Stones 货币、心理测验（焦虑 / 抑郁），以及任何疗效暗示。

4. **周报用「一句话给本周命名」**（D4）
   - 借鉴：Rosebud 的 Weekly Report【截图#3 #5，帮助】
   - 抄什么：标题是本周一句话，加日期范围；下面依次是 ≤5 条关键变化、主题 chips、执行统计（完成条数、时长）、「写满或做满门槛后解锁深度版」。
   - 不抄：Emotional Landscape 情绪诊断图、跨会话长期记忆（隐私评估另做）、「150,000+ Happy Users」式背书；也不学它取消免费层的做法。

### 今日任务

5. **任务卡三要素：难度档、重复规则、「为什么做」**（D5）
   - 借鉴：Habitica 的新建表单（Trivial / Easy / Medium / Hard 和重复规则）【截图#3】；Fabulous 的「Why am I doing this?」【第三方】
   - 抄什么：每条今日任务标明预估时长或难度、重复规则，加一行「对应里程碑 Y」的链接，跳到推演页对应节点。
   - 不抄：HP 扣血、掉级惩罚、金币；Fabulous「科学证明」类话术。

6. **极小第一步 + 次日解锁 + 并行上限**（D5）
   - 借鉴：Fabulous（第一步「本周喝水 3 次」，第二天早上才解锁下一个，同时只能进行一个 Journey）【帮助 + 第三方】
   - 抄什么：建档后第 1 天只给 1–2 条极小任务；完成后第二天再加；同时进行的目标数设上限。
   - 不抄：「来自未来的你：I did it」这种承诺式来信，与我方「模拟非承诺」相冲突。

7. **AI 拆计划要「先展示、确认后写入」，并且可以重试和编辑**（D7）
   - 借鉴：滴答 AI 助手的「目标 → 阶段 → 第一阶段每周计划 → 任务和习惯」，以及建议操作、重试、编辑【帮助】
   - 抄什么：建档后生成计划时，先给阶段树预览，每层可编辑，用户点「加入今日任务」才写入；提供「重新生成」。复盘用三段结构：完成得好的 / 未完成原因（只勾选）/ 调整建议（必含「调整计划」）。
   - 不抄：登录后的具体界面样式（**未核验**，无截图）、额度数值。

### 两线对照 / 变化说明

8. **红绿「已完成 / 未完成」前 3 项归因列表**（D2）
   - 借鉴：Teal Job Matcher 的关键词绿（已有）/ 红（缺失）【帮助】；Habitica 的任务颜色反映历史完成度【FAQ】
   - 抄什么：变化说明里，两线差距下面列出贡献最大的前 3 项：完成项用绿色并写「追回约 1 周」，未完成项用中性灰而不是警示红，并写「晚约 2 周」。同时给「调整计划」入口。
   - 不抄：0–100% Match Score 式的人生或匹配总分；越拖越红的惩罚色；Teal 的薪资目标字段（我方收入走单独的规则和来源）。

### 建档 / 人群

9. **短建档 + 人设标签回显**（D3 防止长问卷）
   - 借鉴：Teal Career Goal 的 4 个字段（目标类型下拉、目标职位、目标日期、薪资区间）【官网】；Rocky 首页人设卡「The Dedicated」【截图#1】；Finch 的引导问卷每屏只问 1 题【第三方】
   - 抄什么：建档每屏一题、总数不超过 5–6 题（年龄、学历、职业大类、城市线级、每周投入）。完成后回显一张「你的人群标签」卡，可以点开修改，标签来源要可追溯（对应 D8 来源角标）。
   - 不抄：DISC 等性格定型测评；「Science-based」宣称；Finch 的手机号强制注册和通讯录权限请求；在引导中途插付费墙。

### 分享与留存

10. **分享卡 = 一句标题 + 3 个指标 + 一句总结**（只放计划线）
    - 借鉴：BitLife 墓碑总结卡的版式（姓名、享年、几项结果、一句墓志铭、Ribbon）【截图#7】；FutureMe 的「Time Travelled」引言卡【截图#2】
    - 抄什么：计划线轨迹缩略图，加一句标题，加 3 个里程碑（不放收入数字），加「AI生成·模拟非承诺」标识。
    - 不抄：死亡和墓碑意象、Ribbon 头衔与评级、实际线与执行记录（已拍板默认不进分享）。人生重开当前没有分享功能，不要引用为先例。

11. **非惩罚式连续天数 + 互助搭子**
    - 借鉴：Finch「30 DAY STREAK」从第 1 天开始庆祝【截图#7，第三方】、Goal Buddies 共享目标【截图#2 #5】；人生重开「别卷了，没有排行榜」的收集统计【源码】
    - 抄什么：只庆祝坚持，不展示断签损失；「有原因暂停」的区间不算断签。搭子功能后置到 M2，只共享「今天完成了」，不共享差距。
    - 不抄：排行榜、通讯录导入、虚拟货币。

12. **「写给 3 个月后的自己」定时回信**（D4 已后置，先留接口）
    - 借鉴：FutureMe 的投递设置（1 / 3 / 5 年、生日、惊喜）、「A letter from <日期>」抬头、寄送天数动画【截图#4 #5，官网】
    - 抄什么：版本对比时显示「这一版生成于 YYYY-MM-DD」的抬头。后续回信送达时，把当时的计划线和现在的实际线并排放，复用变化说明组件。
    - 不抄：公开信墙（UGC 中有未成年人和危机内容，合规风险高）、广告、App 2.74 分的套壳网页实现。
