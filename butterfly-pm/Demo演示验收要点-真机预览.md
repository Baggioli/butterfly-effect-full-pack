# Demo 真机演示验收要点（内部，非正式上线）

## 入口（以开发最新为准）
- 同 Wi‑Fi（优先）：http://192.168.0.109:18888/
- Tailscale：http://100.65.242.127:18888/
- 转发层已注入网关认证，手机一般不必再填系统登录框；若仍弹出：用户名 `owner`，密码见群内开发「预览口令」消息（Micheal 已授权进群）。
- 页面登录：手机号 + mock 验证码 `000000`
- Mac 关机后链接失效；旧 ts.net / 其他 IP 作废。

## 走查顺序（约 5–8 分钟，不含故事等待）
1. 未勾选协议时不能发验证码；勾选后用 mock 码登录。
2. 敏感信息单独同意：默认不勾；拒绝后仍能走文字路径（若本 build 已接）。
3. 语音或文字建档 → 确认角色卡 → 点展开故事。
4. 进度文案：「大约两分钟，偶尔会久一点」；等待中不假称「马上」。
5. 成功：四幕故事 + 今天任务。失败/超时：提示角色卡已保存，可点「重新展开故事」。
6. 「我的」：导出、注销/删除入口可点。
7. 界面无 AI / DGX / Ollama；无算命/成功率承诺；本期不收费。

## 人为故障（必验）
- 展开故事过程中断网或触发失败后：角色卡仍在，重试可成功。
